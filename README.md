# CV Project - Deivid Araya

Portfolio personal y CV interactivo de **Deivid Araya**, Frontend Developer con 6 años de experiencia, basado en Heredia, Costa Rica.

## Stack

- **React 19** + **TypeScript**
- **Vite 6** (build tool)
- **Tailwind CSS 3** (estilos)
- **Framer Motion 12** (animaciones)
- **react-icons** (iconos)
- **gh-pages** (deploy a GitHub Pages)

## Scripts

```bash
npm run dev      # Iniciar servidor de desarrollo
npm run build    # Compilar para producción
npm run preview  # Previsualizar build
npm run lint     # Ejecutar ESLint
npm run deploy   # Desplegar a GitHub Pages
```

## Deploy

El proyecto se despliega automáticamente a **GitHub Pages** mediante GitHub Actions al hacer push a `main`. También se puede desplegar manualmente con `npm run deploy`.
